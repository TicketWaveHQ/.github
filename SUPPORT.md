# Support

Where to go, depending on what you need.

| What you need | Where to go |
|---|---|
| Work with one of our practices | [ticketwavehq.com/contact](https://ticketwavehq.com/contact), or the practice's own site: [VerySEOly](https://veryseoly.com), [JorTech](https://www.jortech.co.uk) or [Dacros](https://dacros.com) |
| Help with the TicketWave booking, ordering or ticketing platform | Reply to your most recent TicketWave email, or write to `hello@ticketwavehq.com` |
| A problem with one of the public repositories in this organisation | Open an issue on that repository |
| The TicketWave API specification | It now lives at [TicketWave-IP/openapi-spec](https://github.com/TicketWave-IP/openapi-spec) |

## I think I have found a security vulnerability

**Do not open a public issue.** Email `security@ticketwavehq.com`, as set out in
[SECURITY.md](SECURITY.md). We acknowledge within two working days.

## I want to report a code-of-conduct violation

Email `conduct@ticketwavehq.com`. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the policy.

## Press, partnerships, investors

`hello@ticketwavehq.com`. Please put "Press", "Partnership" or "Investor" in the subject line so it reaches the right place.
